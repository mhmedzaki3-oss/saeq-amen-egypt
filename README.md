# سائق آمن – مصر

تطبيق توعوي عربي مبسط لسائقي التوك توك.

## محتويات الإصدار
- واجهة عربية RTL مناسبة للهاتف.
- خمسة دروس توعوية، وثلاثة أسئلة لكل درس.
- صوت عربي باستخدام SpeechSynthesis المتاح في المتصفح/الجهاز (ليس تسجيلاً صوتياً بشرياً).
- نقاط تشجيعية وتسجيل التقدم محلياً على نفس الجهاز باستخدام localStorage.
- ملفات PWA للتثبيت من المتصفح والعمل دون اتصال بعد أول تحميل ناجح.
- أيقونتان PNG بمقاسي 192 و512.

## نشره على GitHub Pages
1. أنشئ مستودعاً جديداً على GitHub.
2. ارفع **كل محتويات هذا المجلد** إلى جذر المستودع، بحيث يكون `index.html` في الجذر مباشرة.
3. افتح Settings ثم Pages.
4. من Build and deployment اختر Deploy from a branch.
5. اختر الفرع `main` والمجلد `/ (root)` ثم Save.
6. انتظر اكتمال النشر وافتح الرابط الذي يعرضه GitHub Pages.

## تثبيته على هاتف Android
1. افتح رابط GitHub Pages في Chrome بعد النشر.
2. من قائمة Chrome اختر Install app أو Add to Home screen (قد تختلف التسمية حسب الجهاز).
3. وافق على التثبيت.

هذه طريقة تثبيت PWA، وليست ملف APK مستقلاً. بناء APK يحتاج خطوة Android إضافية واختبار تثبيت فعلي.

## ملاحظات مهمة
- الصوت يعتمد على الأصوات العربية المثبتة في الهاتف، وقد تختلف الجودة واللهجة من جهاز لآخر.
- التقدم والنقاط محفوظان محلياً على الجهاز، ولا تتم مزامنتهما بين الأجهزة.
- يجب تشغيل الدروس والصوت أثناء التوقف في مكان آمن، وليس أثناء القيادة.
- التطبيق للتوعية فقط، ولا يمثل رخصة قيادة أو شهادة معتمدة من المرور، ولا يحل محل القوانين والتعليمات الرسمية.
- راجع الجهات المختصة لأي متطلبات قانونية أو مرورية متغيرة.

## فحص سريع قبل النشر
- افتح `index.html` محلياً للتأكد من ظهور الواجهة.
- بعد النشر اختبر الدروس الخمسة والاختبارات والنقاط والصوت.
- اختبر التثبيت والعمل دون اتصال على هاتف Android.
